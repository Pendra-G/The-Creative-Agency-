Founder portraits.

Save each photo here using the exact filenames below, then hard-refresh:

  salvin.jpg    -> Salvin Shavnit Narayan (SSN)
  upendra.jpg   -> Upendra Gounder (URG)

Square images work best (the card crops to a 64px circle), so roughly
400x400 to 800x800 is plenty. Keep each file under ~150 KB.

If a file is missing the card falls back to the initials plate on its own —
nothing breaks, so you can add them one at a time. Filenames are set in
src/config.js (FOUNDERS[].photo).
